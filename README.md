# 小伙记账 · FirCount

基于 **口袋记账**（`com.qeeniao.mobile.kdjz` v4.5.0）静态逆向分析，用原生 JavaScript 复刻的个人记账应用——零框架、零构建，浏览器直接运行，亦可一键打包为 Android APK。

> 逆向分析证据链 → [ANALYSIS.md](ANALYSIS.md) · APK 构建指南 → [android/BUILD.md](android/BUILD.md)

## 快速开始

```bash
# 浏览器直接运行（file:// 也可）
npx http-server <本目录> -p 8765 -c-1
# 打开 http://127.0.0.1:8765

# 运行测试
npm install && npm test
```

- 首次打开为空账本，点「载入演示数据」可生成近 3 个月示例账单与预算
- Android APK：`cd android && ./build.sh`（详见 BUILD.md），产物按版本号命名：`小伙记账-1.0.6.apk`

## 功能总览

### 界面布局

```
┌─────────────────────────────┐
│                             │
│   页面内容（账单为默认页）    │
│                             │
├─────────────────────────────┤
│  📊 报表  │  📋 账单  │ 👤 我的 │  ← 三个主 Tab
└─────────────────────────────┘
```

- **账单**（默认页）：账本切换、月份切换、日小计、月收支合计；**激活账单页时中间 Tab 变为「＋ 记一笔」**
- **＋ 记一笔按钮**：位于底栏中间，账单页激活时显示（其他页显示「账单」）；受应用锁保护
- **我的**：钱包资产管理（带净资产摘要）、多账本管理、预算、分类管理、数据导入导出、应用锁、WebDAV 同步等

### 记一笔（核心页面）

```
┌──────────────────────────────┐
│  支出 │ 收入 │ 转账            │  ← 模式切换
│  选中分类大图标 + 金额 + 公式  │
├──────────────────────────────┤
│  🍜   🛍️   🚌   👕            │
│  24 类全量宫格（4 列，不分页） │  ← 内部滚动；长按：编辑/排序/移除
│  …   ＋添加                   │
├──────────────────────────────┤
│ 📅月日│账户│成员│🏷│📷│✎       │  ← 快捷条，常驻键盘上方
├──────────────────────────────┤
│  7 8 9 ⌫ / 4 5 6 + / … OK    │  ← 计算器键盘（固定底部）
└──────────────────────────────┘
```

- 三种模式：支出 / 收入 / 转账（转账隐藏账户/成员快捷按钮）
- 24 个支出分类与导出数据完全一致；自定义分类随时添加，**长按可编辑 / 拖动排序 / 移除**
- 快捷条：日期（日历式选择器）、账户、成员（点击轮换）、标签、附件（≤3 张自动压缩）、备注

### 记账核心

| 功能 | 说明 |
|---|---|
| 计算器键盘 | 4×4 键盘，公式实时计算（12+8×2 连算），支持物理键盘 |
| 多账本 | 新建/切换/重命名/删除，账单随账本隔离；账单页顶部一键切换 |
| 账户钱包 | 现金/储蓄卡/信用卡/网络账户/虚拟卡/投资/负债 7 类；净资产总览；信用卡额度/账单日/还款日 |
| 账户转账 | 双向余额变动 |
| 预算 | 月总预算 + 分类预算，日/周/月三进度环 |
| 标签 | 多选标签、账单显示 #标签、按标签筛选 |
| 附件 | 每笔最多 3 图（自动压缩 ~720px），管理弹层：缩略图/全屏查看/删除 |
| 日历视图 | 月历每日收支标记 |
| 搜索 | 备注/分类/账户/金额全文搜索 |
| 成员 / 多币种 | 多成员记账；¥ $ € £ ₩ |
| 深色模式 | 全套深色变量主题 |

### 报表（三种时间范围）

| 模式 | 范围 | 切换方式 |
|---|---|---|
| 按月（默认当前月） | 当月 | ‹ › 逐月切换；**点击标题弹月份网格直选** |
| 按年 | 全年 | ‹ › 逐年切换；**点击标题弹年份网格直选** |
| 自定义 | 任意起止日期（精确到日，自动纠错） | 起止字段点击弹日历式选择器 |

- 分类占比环形图 + 图例、分类排行（除零保护）
- 收支趋势折线：月模式展示近 6 个月；年/自定义模式按自然月聚合（跨度 >24 个月自动隐藏）
- KPI：总额 / 笔数 / 最高单笔 / 记账天数（占区间总天数）

### 数据导入导出

| 功能 | 说明 |
|---|---|
| 导出 | CSV（Excel 可开）/ JSON 完整备份 |
| **CSV 导入** | 支持口袋记账导出格式（时间/账目分类/金额），分类名精确匹配+别名映射+未知自动创建；合并去重或覆盖；导入前预览 |
| **XLSX 导入** | SheetJS 解析；按 ZIP 魔数识别格式（不依赖文件扩展名）；多工作表自动选行数最多者；Excel 序列日期自动转换 |
| 导入诊断 | 失败时提示文件名/字节数/首行内容 |

### 安全

| 功能 | 说明 |
|---|---|
| 应用锁 | 4~6 位 PIN（SHA-256 加盐），启动必验 + 切后台按配置时长重验 |
| 指纹解锁 | APK 内 FingerprintManager 实现，锁屏一键验证，失败回退 PIN |
| 找回 | 安全问题验证后重置 PIN（数据保留） |
| 清空数据 | 需输入随机 6 位确认码（强制含大小写+数字+符号）；**仅清记账数据，保留 WebDAV 配置与应用锁** |

### 云同步（坚果云 WebDAV，仅 APK）

**备份范围（完整状态，不只账单）**：账单 · 账本 · 账户（含信用卡额度/账单日/还款日）· 分类（含自定义/图标/排序）· 预算 · 标签 · 成员 · 主题 · 币种
**不含设备凭证**：WebDAV 账号/应用密码、应用锁 PIN/答案哈希（防止密码随备份上传云端；恢复时保留本机凭证）

| 能力 | 说明 |
|---|---|
| 服务商 | 预设**坚果云** / 123网盘 / 自定义（仅 https）；坚果云需网页版生成**应用密码** |
| 测试连接 | HEAD 标准方法验证，失败分场景提示（401 密码错 / 403 设备并发或流量超限 / 网络不通） |
| **自动备份** | 记账后 N 秒自动推送（1~3600 秒可配置，默认 5 秒，去抖合并）+ 每 24 小时兜底检查 |
| 恢复 | 云端备份列表（PROPFIND 失败自动降级 GET），二次确认覆盖；恢复保留本机凭证 |
| 文件管理 | 文件名 `firecount_YYYYMMDD_HHMMSS.json` + `latest.json`；保留份数默认 1（1~5 可输入），滚动清理 |
| 防丢失 | 本地双存储兜底（SQLite 主槽 + head_bak 备份槽 / localStorage 主槽 + :bak 槽），配置不会被意外清空 |

### 桌面快捷方式

长按应用图标：「记一笔」（受应用锁保护）、「立即同步备份」。

### 弹层体系

- **主弹层**（记一笔等）：单例，连点不叠加
- **子弹层**（从主弹层打开的标签/附件/备注/账户/分类编辑/日期选择器等）：叠在主层之上，关闭后回到主层；同层互斥

## 架构

```
firecount/
├── index.html                 # 入口，脚本按依赖序加载
├── css/style.css              # 全部样式（深色模式变量、报表模式栏、快捷条等）
├── img/appicon.png            # 应用图标（我的页头像复用）
├── js/
│   ├── icons.js               # 65+ 线性 SVG 图标库 + IconUI 渲染（emoji 兼容回退）
│   ├── xlsx.mini.min.js       # SheetJS mini 0.20.3
│   ├── data.js                # 静态数据：默认分类（24 支出+9 收入）/账户类型/币种
│   ├── store.js               # 状态管理、双通道持久化、分类同步迁移、导入导出引擎
│   ├── ui.js                  # 弹层（主/子分级单例）/toast/确认框/日期与年月选择器
│   ├── lock.js                # 应用锁（PIN + 指纹 + 找回）
│   ├── webdav.js              # 坚果云同步、自动备份策略、防丢失双存储
│   ├── charts.js              # 纯 JS 图表（饼图/折线/进度环）
│   ├── views-*.js             # 页面：账单(含日历/搜索)/记一笔/报表/钱包/我的
│   └── app.js                 # 路由、Tab 条件渲染、快捷方式分发、边缘滑动返回
├── android/
│   ├── BUILD.md / build.sh    # 一键构建（aapt2/d8/zipalign/apksigner）
│   └── app/
│       ├── AndroidManifest.xml
│       ├── res/xml/shortcuts.xml
│       └── java/com/fircount/MainActivity.java   # WebView 壳：
│           · SQLite 桥（异步单线程写入队列 + head_bak 备份槽）
│           · 指纹认证桥（FingerprintManager + CancellationSignal）
│           · WebDAV HTTP 代理（反射支持 PROPFIND/MKCOL，标准 UA）
│           · 快捷方式分发                     · 边缘滑动/返回键逐级返回
├── tests/                     # 自动化测试（jsdom，178 项）
└── ANALYSIS.md                # 口袋记账逆向分析报告
```

**设计要点**

- 无框架：`App` 对象做路由（PAGES 表 + 页面栈），页面手写 HTML 字符串渲染
- 数据层双通道：浏览器用 localStorage（含 :bak 备份槽）；APK 经 JS 桥写原生 SQLite（去抖合并写入 + head_bak 兜底）
- 原生壳仅 4 件事：SQLite、指纹、WebDAV 代理、系统选择器；其余全在 Web 层
- 弹层主/子分级：`UI.sheet()` 单点控制防连点叠加，`opts.sub` 支持子弹层栈

## 数据安全

- 纯本地运行，数据仅存设备（SQLite / localStorage）；WebDAV 凭证也仅存本地
- 备份文件**不携带** WebDAV 密码、应用锁 PIN 哈希等设备凭证（分享备份不泄露）
- 清空数据有强确认码保护，且只清记账数据、保留同步配置
- 建议开启自动备份（记账后 5 秒推送），换机/重装可从坚果云一键恢复
