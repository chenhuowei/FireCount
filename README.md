# 小伙记账 · FirCount

基于 **口袋记账**（`com.qeeniao.mobile.kdjz` v4.5.0）静态逆向分析，用原生 JavaScript 复刻的个人记账应用——零框架、零构建，浏览器直接运行，亦可一键打包为 Android APK。

> 逆向分析证据链 → [ANALYSIS.md](ANALYSIS.md) · APK 构建指南 → [android/BUILD.md](android/BUILD.md)

---

## 基本信息

| 项 | 值 |
|---|---|
| 项目代号 | FirCount |
| 应用名 | 小伙记账 |
| Android 包名 | `com.fircount` · versionCode 5 · versionName 1.0.5 |
| 环境 | minSdk 24 / targetSdk 34 |
| 技术栈 | 原生 JavaScript SPA（无框架、无构建步骤）+ 单 Activity WebView 壳 |
| 运行时依赖 | 仅 SheetJS mini 0.20.3（XLSX 解析，Apache-2.0） |
| 权限 | `INTERNET`（仅 WebDAV 同步）、`USE_FINGERPRINT` |

## 快速开始

```bash
# 浏览器直接运行（file:// 也可）
npx http-server <本目录> -p 8765 -c-1
# 打开 http://127.0.0.1:8765
```

- 首次打开为空账本，点「载入演示数据」可生成近 3 个月示例账单与预算
- Android APK：`cd android && ./build.sh`（详见 BUILD.md），产物按版本号命名：`小伙记账-1.0.5.apk`

## 功能总览

### 界面布局

```
┌─────────────────────────────┐
│                             │
│         页面内容      (＋)  │  ← 悬浮记账按钮：长按可拖动换位
│                             │
├─────────────────────────────┤
│  📊 报表  │  📋 账单  │ 👤 我的 │  ← 三个主 Tab，账单为默认页
└─────────────────────────────┘
```

- **＋ 悬浮球**：默认居中于底栏上方；**长按 350ms 进入拖动模式**，水平位置任意调整并自动记忆（双击复位）；点击打开记一笔（受应用锁保护）
- **账单**（默认页）：账本切换、月份切换、日小计、月收支合计；激活账单页时中间按钮变为「＋ 记一笔」快捷入口
- **报表 / 我的**：见下文

### 记账核心

| 功能 | 说明 |
|---|---|
| 记一笔三模式 | 支出 / 收入 / 转账；4×4 计算器键盘，公式实时计算 |
| 分类宫格 | 多页滑动 + 指示点；自定义分类随时添加 |
| 分类图标 | 65+ 手绘线性 SVG（Tabler 风格，按分类色着色），自定义分类可选图标或 emoji |
| 多账本 | 新建/切换/重命名/删除，账单随账本隔离 |
| 账户钱包 | 现金/储蓄卡/信用卡/网络账户/虚拟卡/投资/负债 7 类；净资产总览；信用卡额度/账单日/还款日 |
| 账户转账 | 双向余额变动 |
| 预算 | 月总预算 + 分类预算，日/周/月三进度环 |
| 标签 | 多选标签、账单显示 #标签、按标签筛选 |
| 附件 | 每笔最多 3 图（自动压缩 ~720px），列表缩略图、全屏查看 |
| 日历视图 | 月历每日收支标记 |
| 搜索 | 备注/分类/账户/金额全文搜索 |
| 成员 / 多币种 | 多成员记账；¥ $ € £ ₩ |
| 深色模式 | 全套深色变量主题 |

### 报表（三种时间范围）

| 模式 | 范围 |
|---|---|
| 按月（默认当前月） | 月份左右切换 |
| 按年 | 全年聚合 |
| 自定义 | 任意起止日期（精确到日，起止自动纠错） |

- 分类占比环形图 + 图例、分类排行
- 收支趋势折线：月模式展示近 6 个月；年/自定义模式按自然月聚合（跨度 >24 个月自动隐藏）
- KPI：总额 / 笔数 / 最高单笔 / 记账天数（占区间总天数）

### 数据导入导出

| 功能 | 说明 |
|---|---|
| 导出 | CSV（Excel 可开）/ JSON 完整备份 |
| **CSV 导入** | 支持口袋记账导出格式（时间/账目分类/金额），分类名自动映射、未知分类自动创建（配图标）；合并去重或覆盖；导入前预览 |
| **XLSX 导入** | SheetJS 解析；按 ZIP 魔数识别格式（不依赖文件扩展名，兼容安卓选择器）；多工作表自动选行数最多者；Excel 序列日期自动转换 |
| 导入诊断 | 失败时提示文件名/字节数/首行内容 |

### 安全

| 功能 | 说明 |
|---|---|
| 应用锁 | 4~6 位 PIN（SHA-256 加盐），启动必验 + 切后台按配置时长重验 |
| 指纹解锁 | APK 内 FingerprintManager 实现，锁屏一键验证，失败回退 PIN |
| 找回 | 安全问题验证后重置 PIN（数据保留） |
| 清空数据 | 需输入随机 6 位确认码（强制含大小写+数字+符号，可换一个）才可执行；**仅清本地**，云端备份不受影响 |

### 云同步（坚果云 WebDAV，仅 APK）

- 预设坚果云 / 123网盘 / 自定义（仅 https）；坚果云需在网页版生成**应用密码**
- **测试连接**：HEAD 标准方法验证，失败按 401（密码错）/ 403（设备并发或流量超限）/ 网络不通 分场景提示
- **自动备份**：记账后 N 秒自动推送（**1~3600 秒可配置**，默认 5 秒，连续记账去抖合并）+ 每 6 小时兜底检查
- 恢复：云端备份列表（PROPFIND 失败自动降级 GET 解析），二次确认覆盖
- 版本滚动清理（5/10/20 份可配）

### 桌面快捷方式

长按应用图标：「记一笔」（应用锁保护）、「立即同步备份」。

## 架构

```
firecount/
├── index.html                 # 入口，脚本按依赖序加载
├── css/style.css              # 全部样式（深色模式变量、FAB、报表模式栏）
├── js/
│   ├── icons.js               # 65+ 线性 SVG 图标库 + IconUI 渲染（emoji 兼容回退）
│   ├── xlsx.mini.min.js       # SheetJS mini 0.20.3
│   ├── data.js                # 静态数据：默认分类/账户类型/币种
│   ├── store.js               # 状态管理、SQLite/localStorage 持久化、导入导出引擎
│   ├── ui.js                  # 弹层/toast/确认框/密码可见切换
│   ├── lock.js                # 应用锁（PIN + 指纹 + 找回）
│   ├── webdav.js              # 坚果云同步、自动备份策略
│   ├── charts.js              # 纯 JS 图表（饼图/折线/进度环）
│   ├── views-*.js             # 页面：账单/记一笔/报表/钱包/我的
│   └── app.js                 # 路由、Tab、FAB 拖动、快捷方式分发
├── android/
│   ├── BUILD.md / build.sh    # 一键构建（aapt2/d8/zipalign/apksigner）
│   └── app/
│       ├── AndroidManifest.xml
│       ├── res/xml/shortcuts.xml
│       └── java/com/fircount/MainActivity.java   # WebView 壳：
│           · SQLite 桥（异步单线程写入队列）  · 指纹认证桥
│           · WebDAV HTTP 代理（反射支持 WebDAV 方法，标准 UA）
│           · 快捷方式分发                     · 边缘滑动/返回键逐级返回
├── tests/                     # 自动化测试（jsdom）
│   ├── run-all.js             # 一键全量入口（npm test）
│   ├── harness.js             # 测试环境 + 断言框架
│   └── 01~04 + static-audit   # 五套测试
└── ANALYSIS.md                # 口袋记账逆向分析报告
```

**设计要点**

- 无框架：`App` 对象做路由（PAGES 表 + 页面栈），页面手写 HTML 字符串渲染
- 数据层双通道：浏览器用 localStorage；APK 经 JS 桥写原生 SQLite（去抖合并写入，UI 永不阻塞）
- 原生壳仅 4 件事：SQLite、指纹、WebDAV 代理、系统选择器；其余全在 Web 层

## 数据安全

- 纯本地运行，数据仅存设备（SQLite / localStorage）；WebDAV 凭证也仅存本地
- 清空数据有强确认码保护，且只影响本地
- 建议开启自动备份，换机/重装可从坚果云一键恢复
